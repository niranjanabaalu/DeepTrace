# DeepTrace — AI-Based Deepfake Video Detection

DeepTrace is an experimental AI-powered web application that analyzes uploaded videos and predicts whether they are **REAL** or **FAKE**. It combines face detection, deep-learning-based image classification, video-level score aggregation, and explainable AI visualization in a Django web application.

> **Disclaimer:** DeepTrace is an experimental prototype. Its predictions are not forensic proof of authenticity, and its performance has not been validated for reliable real-world deepfake detection.

## Features

- **Video Upload:** Upload supported video formats for analysis.
- **Face Detection:** Use YuNet to locate faces in sampled video frames.
- **Deepfake Classification:** Use EfficientNet-B0 to classify extracted face crops.
- **Video-Level Prediction:** Aggregate face-crop scores to produce an overall REAL or FAKE prediction.
- **Analysis Statistics:** Display prediction scores, sampled-frame counts, and face-analysis statistics.
- **Explainable AI:** Use Grad-CAM heatmaps to inspect image regions that influence model predictions.
- **User Authentication:** Provide account registration, sign-in, and logout functionality.
- **Analysis Output:** Access technical output generated by the analysis script.

## How It Works

1. The user signs in and uploads a video.
2. Django validates the file extension and saves the upload.
3. The analysis script reads the video and samples frames.
4. YuNet detects faces in the sampled frames.
5. Detected faces are cropped and preprocessed.
6. EfficientNet-B0 predicts fake and real scores for each analyzed face crop.
7. The scores are aggregated to generate a video-level prediction.
8. The application displays the result and analysis statistics.
9. Grad-CAM can be used to visualize regions influencing a classifier prediction.

## Dataset

The documented experiment uses a subset of **FaceForensics++**, specifically original YouTube videos and manipulated videos from the Deepfakes category using the c23 compressed-video version.

The documented dataset contains 100 source videos:

- 50 original videos
- 50 manipulated videos

The face-crop dataset contains 5,878 samples:

- Training: 3,784 crops
- Validation: 638 crops
- Testing: 1,456 crops

Dataset usage must follow the original dataset's access conditions and license. Do not upload restricted dataset videos or face crops to this repository.

## Experimental Results

The documented experiment reported:

| Evaluation                |                    Result |
| ------------------------- | ------------------------: |
| Face-crop test accuracy   |                    66.48% |
| Video-level test accuracy | 80% (16 out of 20 videos) |

The video-level evaluation uses only 20 test videos, so the result is preliminary and should not be interpreted as evidence of reliable real-world performance.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/DeepTrace.git
cd DeepTrace
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Create a virtual environment

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can run the environment's Python executable directly or use Command Prompt activation instead.

### 3. Install dependencies

If the repository contains a `requirements.txt` file:

```bash
python -m pip install -r requirements.txt
```

If it does not, create one from the project's actual imports and tested environment before running the application. Do not assume that every dependency is included automatically.

### 4. Configure model files

Place the required EfficientNet-B0 checkpoint and YuNet ONNX file in the locations expected by the analysis code. Verify the paths in the training and inference scripts.

### 5. Apply database migrations

```bash
python manage.py migrate
```

### 6. Start the development server

```bash
python manage.py runserver
```

Open the local address shown in the terminal, usually:

http://127.0.0.1:8000/

Create an account or sign in to access the application.

## Limitations

- The model may produce false-positive and false-negative predictions.
- Frame sampling may miss manipulations that occur between sampled frames.
- Performance may vary with compression, lighting, resolution, and face visibility.
- The evaluation dataset is limited and does not represent every real-world deepfake technique.
- Model scores are not guaranteed to be calibrated probabilities.
- Grad-CAM visualizations indicate influential regions; they do not prove that a video is manipulated.
